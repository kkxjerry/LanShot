# LanShot 统一模式

更新时间：2026-09-16。

LanShot 与 LanShot2 已通过统一控制器合并。两种模式互斥，切换时先停止当前模式再启动目标模式。

运行后点击菜单栏 LanShot 图标，通过“模式”子菜单可直接切换截屏模式和面试模式；当前模式带选中标记。

## 截屏模式

- 保留原有截图、AI分析和悬浮窗。
- 配置知识库后，先用 macOS Vision 本地 OCR 提取查询并检索，再调用原截图模型。
- F22截图，F23/F24翻页，Command+F23显隐。
- 不启动双路音频采集。

## 面试模式

- 只启动系统音频和麦克风双路实时ASR。
- 两路都使用 `qwen-audio-3.0-asr-flash-streaming`。
- 不启动截图快捷键；启动同款不可捕获悬浮窗，实时显示两路文字。
- 菜单栏使用麦克风图标标识语音模式，可显隐或居中字幕。
- 进入语音模式后处于待机状态，不采集声音；点击“开始采集”后显示具体开始时间和计时。
- 语音模式的首次开始与手动停止使用界面按钮；`F22` 固化当前两路快照后立即恢复下一轮识别，LLM 回答在后台并行生成；`F23` / `F24` 向上/向下翻页。
- 悬浮窗上方 35% 左右分栏显示系统声音和麦克风，下方 65% 显示答案。
- 文字与音频保存在 `~/Library/Application Support/LanShot2/audio/`。
- 配置知识库后，两路转写会在调用回答模型前执行检索。

## 使用

双击 `LanShot.command`，在原生对话框中选择截屏模式、面试模式或全部停止。

也可以直接双击：

- `screenshot_mode.command`
- `voice_mode.command`
- `stop_all.command`
- `status.command`
- `configure_knowledge.command`
- `test_knowledge.command`

程序不会自动开始第一次语音监听。切换到面试模式只显示待机界面，必须明确点击“开始采集”。点击“停止采集”只保存本轮；按 `F22` 会发送问题并立即恢复下一轮识别，不等待答案生成。`F23` / `F24` 用于翻页。切换到截屏模式或全部停止时，音频采集立即结束。

语音模式也可通过菜单栏麦克风图标中的“退出 LanShot”完整退出；该操作会先保存当前记录，不会留下悬浮窗或快捷键控制器。

“会话管理...”窗口用于新建、查看和继续面试会话。每个会话拥有独立的最近问答上下文，切换会话不会删除旧录音、问题或答案。

知识检索是可选增强。未配置或检索失败时两个模式都继续使用原回答流程，不停止进程，也不清理会话。
