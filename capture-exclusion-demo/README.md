# 原生悬浮显示接入修订

原生窗口、字体/颜色设置、翻页、移动等既有交互保留。新增菜单手动截图、可配置状态目录、版本化状态读取、显示回执和失联提示。不使用 Tk。

在 macOS 编译：`sh build.sh`。编译成功前不删除旧应用，替换时保留时间戳备份。该修订包在 Linux 完成 Python/接口测试，不能据此宣称 Swift/AppKit 已编译或在牛客验证。

应用通过 `--lanshot-display-dir /绝对路径` 读取新目录中的 `latest_state.json` 和 `page.txt`，写入 `display_ack.json` 和 `overlay_status.json`。无此参数时保留旧目录读取兼容，但不能宣称版本回执已接入。

原源码中的窗口共享属性没有新增或加强；它们不构成免于系统/第三方采集的保证。此次没有实现或验证规避平台检测的能力。
