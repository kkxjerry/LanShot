### 稳定低分

Q01：70-80，均值75.33。
反复遗漏：
- Function Calling 与 ReAct 可以组合；
- 工具选择 / 参数结构 / 参数内容 / 端到端成功率四层；
- 格式正确 != 工具选对 != 业务结果正确；
- 微调前先做工具描述、候选筛选等工程优化。

Q05：78-84，均值80.67。

- GQA / PagedAttention / 低精度 KV 分别解决什么。

Q12：77-81，均值79。
